พื้นที่ของคุณ ⚙

AI ของคุณ ทางเลือกของคุณ

เลือกบริการและโมเดลที่ต้องการ ค่าใช้งานคิดกับบัญชีของคุณเมื่อกดใช้ฟีเจอร์ AI

⚙ เชื่อมต่อ AI ของคุณProvider · Model · API key ＋

เมื่อเลือก MaxPlus ข้อความงานวิจัยจะส่งไปที่บริการนี้ ใช้ API key ของ MaxPlus และชื่อโมเดลตามที่ผู้ให้บริการระบุ

ข้อความและ metadata จะส่งไปยังบริการที่เลือก ค่า API คิดกับบัญชีของคุณ คีย์เก็บในหน่วยความจำหน้านี้ ผ่านเซิร์ฟเวอร์เพื่อเรียกบริการ และไม่บันทึกในคุกกี้หรือ storage

เป็นตัวเลือก ใช้ local storage เก็บเฉพาะการตั้งค่า ไม่เก็บ API key, PDF หรือบทสนทนา ปิดเพื่อถอนความยินยอมและลบค่าที่จำไว้

ไปยังสิ่งที่ต้องการ

เครื่องมือทั้งหมดในพื้นที่เดียว

ใช้บนอุปกรณ์ร่วมกัน

ล้าง API key และดาวน์โหลดผลก่อนปิดแท็บ การรีเฟรชหน้าอาจทำให้ไฟล์ แช็ต และผลที่ไม่ได้บันทึกหาย เปิดผลที่บันทึกแล้วได้จากหมวดประวัติ

กลับไปดูสิ่งที่ค้นพบ

เก็บผลใน IndexedDB ของเบราว์เซอร์นี้ ไม่ซิงก์คลาวด์ ไม่เก็บ API key หรือ PDF เก็บ metadata สรุป AI และตำแหน่งกราฟในอุปกรณ์นี้

ปิดเพื่อหยุดบันทึกใหม่ ประวัติเดิมยังอยู่ เก็บล่าสุดสูงสุด 50 รายการ / 8 MB เมื่อเต็มจะนำรายการเก่าสุดออก ผู้ที่ใช้เบราว์เซอร์เดียวกันอาจเปิดดูได้

หยุดบันทึกชั่วคราวในแท็บนี้และใช้ธีมมืด เมื่อปิดจะกลับไปใช้การตั้งค่าบันทึกเดิม ประวัติเดิมยังอยู่

เลือก 0 เปเปอร์

ส่ง metadata/abstract/สรุปที่บันทึกของเปเปอร์ที่เลือกไปยัง AI เมื่อกดเปรียบเทียบ คิดค่า API ตามบัญชีของคุณ

เก็บเฉพาะผลการค้นหา

เปิดผลเดิมได้โดยไม่ค้นใหม่ แต่การวิเคราะห์ AI ที่ต้องอ่าน PDF ต้องแนบไฟล์อีกครั้ง การล้างข้อมูลเว็บไซต์หรือโหมดส่วนตัวอาจทำให้ประวัติหาย ดาวน์โหลดสำรองไว้หากต้องการย้ายเครื่องหรือย้าย URL แอป

ข้อมูลไปที่ไหนบ้าง?

เลือกใช้แต่ละฟีเจอร์ได้ โดยไม่ต้องเปิดการจำค่าตั้งต้น

PDF และการค้นหา

PDF ผ่านเซิร์ฟเวอร์เพื่อสกัดข้อความ การค้นอ้างอิงส่ง DOI ชื่อเรื่อง หรือ metadata ไปยังฐานข้อมูลวิชาการที่ใช้ ฟีเจอร์ AI ส่งบริบทที่จำเป็นและคีย์ผ่านเซิร์ฟเวอร์ไปยัง provider ที่เลือก

API key และผลการทำงาน

แอปไม่บันทึกคีย์ PDF หรือแช็ตลง storage ของเบราว์เซอร์หรือไฟล์ถาวรของแอป ประวัติรายการอ้างอิงเก็บใน IndexedDB บนอุปกรณ์นี้เมื่อเปิดบันทึก และลบได้ในหมวดประวัติ ข้อมูลคำขออยู่ในหน่วยความจำระหว่างประมวลผล นโยบายเก็บข้อมูลของผู้ให้บริการ AI และผู้ให้บริการโฮสต์อาจแตกต่างกัน

คุกกี้และบริการภายนอก

แอปไม่ตั้งคุกกี้โฆษณาหรือติดตาม Streamlit อาจใช้คุกกี้ที่จำเป็นสำหรับความปลอดภัยและการเชื่อมต่อ ฟอนต์โหลดจาก Google Fonts และลิงก์บทความเปิดเว็บไซต์ภายนอกซึ่งมีนโยบายของตนเอง

การจำ provider/โมเดลเป็นตัวเลือกที่ปิดไว้ก่อน และถอนโดยปิดสวิตช์ในหมวดเชื่อมต่อ AI ได้ทุกเมื่อ

ก่อนส่งข้อมูล

เลือก provider ที่คุณยอมรับนโยบายข้อมูล และหลีกเลี่ยงการส่งเอกสารที่มีข้อมูลส่วนบุคคลหรือข้อมูลที่คุณไม่มีสิทธิ์แชร์
